Defense-in-Depth Principles

Six Pillars of Enterprise Legal Safe Architecture

Our technical safeguards guarantee confidentiality, data integrity, and strict segregation across every tier of the platform.

Multi-Tenant Isolation

Every contract, template, finding, and audit record is strictly foreign-keyed to an organization_id. Cross-tenant access is blocked at the database query layer with mandatory 404 security barriers.

SHA-256 Deduplication

Streaming SHA-256 cryptographic checksums compute file hashes upon upload, preventing duplicate processing, double database writes, token waste, and accidental double-signatures.

Internal Service Auth

Microservice communication between Node.js and the Python FastAPI AI service is gated by constant-time verified X-Internal-Key headers, preventing timing attacks and unauthorized direct calls.

Tamper-Evident Audit

All user logins, contract uploads, analysis runs, findings updates, and partner decisions are immutably logged with timestamp, user ID, client IP address, and entity context.

Air-Gapped Deployment

Clausify supports local deterministic vector embedding and rules evaluation (Mock providers) without sending contract bytes to external cloud APIs, enabling air-gapped on-premise execution.

Zero Model Retraining

Client contracts are strictly ephemeral processing inputs. Contract texts and redlines are NEVER stored in public weights or utilized to retrain commercial AI models.
